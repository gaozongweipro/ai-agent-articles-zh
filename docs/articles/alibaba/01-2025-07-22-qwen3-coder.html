Qwen3-Coder：在世界中进行智能体式编程

今天，我们宣布推出迄今最具智能体特性的代码模型 Qwen3-Coder。Qwen3-Coder 将提供多种规模，我们先介绍其中最强的变体：Qwen3-Coder-480B-A35B-Instruct——一个总参数 480B、激活 35B 的混合专家模型，原生支持 256K tokens 的上下文，并可用外推方法扩展到 1M tokens，在编程与智能体任务上都有出色表现。Qwen3-Coder-480B-A35B-Instruct 在开源模型中于 Agentic Coding、Agentic Browser-Use 和 Agentic Tool-Use 上取得新的领先结果，可与 Claude Sonnet 4 相比。

与模型同时，我们还开源了面向智能体式编程的命令行工具 Qwen Code。它从 Gemini Code 分叉而来，并针对 Qwen3-Coder 定制了提示与函数调用协议，以充分释放其在智能体式编程任务上的能力。Qwen3-Coder 也能与社区中优秀的开发者工具顺畅配合。作为基础模型，我们希望它能在数字世界的各处被使用——Agentic Coding in the World。

Qwen3-Coder

预训练

预训练仍有扩展空间。在 Qwen3-Coder 上，我们沿多个维度加强模型的核心能力：

  • 扩展 Tokens：7.5T tokens（约 70% 为代码），在强化编程的同时保留通用与数学能力。
  • 扩展上下文：原生支持 256K，并可用 YaRN 扩展到 1M，针对仓库级与动态数据（例如 Pull Request）做了优化，以支撑 Agentic Coding。
  • 扩展合成数据：利用 Qwen2.5-Coder 清理并改写嘈杂数据，显著提升整体数据质量。

后训练

Scaling Code RL：难求解、易验证

与社区多聚焦竞赛级代码生成不同，我们认为几乎所有代码任务天生适合以执行为驱动的大规模强化学习。因此我们在更广泛的真实编程任务上扩大了 Code RL 训练。通过自动扩展多样化编码任务的测试用例，我们构造了高质量训练实例，并成功释放了强化学习的潜力。它不仅显著提高了代码执行成功率，也给其他任务带来收益。这鼓励我们继续把「难求解、易验证」的任务，作为大规模强化学习的沃土。

Scaling Long-Horizon RL

在 SWE-Bench 这类真实软件工程任务中，Qwen3-Coder 必须与环境进行多轮交互，包括规划、使用工具、接收反馈并做决策。在后训练阶段，我们引入长时程强化学习（Agent RL），鼓励模型通过多轮工具交互解决真实任务。Agent RL 的关键挑战在于环境扩展。为此，我们借助阿里云基础设施，搭建了可并行运行 20,000 个独立环境的可扩展系统，为大规模强化学习提供反馈，并支持大规模评估。因此，Qwen3-Coder 在无需 test-time scaling 的情况下，于 SWE-Bench Verified 上取得开源模型中的领先成绩。

使用 Qwen3-Coder 编程

Qwen Code

Qwen Code 是从 Gemini CLI 改编的研究用途 CLI 工具，增强了针对 Qwen-Coder 模型的解析器与工具支持。

请确保已安装 Node.js 20+。可通过如下命令安装 npm：

curl -qL https://www.npmjs.com/install.sh | sh

然后用 npm 安装 Qwen Code：

npm i -g @qwen-code/qwen-code

也可从源码安装：

git clone https://github.com/QwenLM/qwen-code.git
cd qwen-code && npm install && npm install -g

Qwen Code 在调用 LLM 时支持 OpenAI SDK，你可导出以下环境变量，或把它们放在 .env 文件中：

export OPENAI_API_KEY="your_api_key_here"
export OPENAI_BASE_URL="https://dashscope-intl.aliyuncs.com/compatible-mode/v1"
export OPENAI_MODEL="qwen3-coder-plus"

现在，输入 qwen 即可与 Qwen-Code 和 Qwen 一起进行 vibe coding。

Claude Code

除 Qwen Code 外，你也可以在 Claude Code 中使用 Qwen3-Coder。只需在阿里云百炼（Model Studio）申请 API key 并安装 Claude Code 即可开始。

npm install -g @anthropic-ai/claude-code

我们提供了两种顺畅体验 Qwen3-Coder 编程的入口。

可选 1：Claude Code 代理 API

export ANTHROPIC_BASE_URL=https://dashscope-intl.aliyuncs.com/api/v2/apps/claude-code-proxy
export ANTHROPIC_AUTH_TOKEN=your-dashscope-apikey

然后即可在 Claude Code 中使用 Qwen3-Coder。

可选 2：用 claude-code-config npm 包自定义路由

claude-code-router 用于为 Claude Code 定制不同的后端模型。DashScope 团队还提供了便捷的配置扩展 @dashscope-js/claude-code-config，为带 DashScope 支持的 claude-code-router 提供默认配置。安装：

npm install -g @musistudio/claude-code-router
npm install -g @dashscope-js/claude-code-config

然后运行配置：

ccr-dashscope

该命令会自动生成 ccr 所需的配置 JSON 与插件目录（也可手动调整 ~/.claude-code-router/config.json 与 ~/.claude-code-router/plugins/）。通过 ccr 启动 Claude Code：

ccr code

Cline

将 Qwen3-Coder-480B-A35B-Instruct 配置到 Cline：打开 Cline 配置——API Provider 选择 “OpenAI Compatible”——填入从 DashScope 获取的 API Key——勾选 “Use custom base URL” 并填入 https://dashscope-intl.aliyuncs.com/compatible-mode/v1——模型名填写 qwen3-coder-plus。

API

你可以通过阿里云百炼直接访问 Qwen3-Coder 的 API。下面演示如何用 Qwen API 调用该模型。

import os
from openai import OpenAI

# 创建客户端——中国大陆以外用户使用 intl URL
# 若在中国大陆，请使用：
# "https://dashscope.aliyuncs.com/compatible-mode/v1"
client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://dashscope-intl.aliyuncs.com/compatible-mode/v1",
)

prompt = "Help me create a web page for an online bookstore."

completion = client.chat.completions.create(
    model="qwen3-coder-plus",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": prompt}
    ],
)

print(completion.choices[0].message.content.strip())
