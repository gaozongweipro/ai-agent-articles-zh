# DeepSeek-V3.1 发布

推出 DeepSeek-V3.1：我们迈向智能体时代的第一步。

- 混合推理：Think 与 Non-Think——一个模型，两种模式
- 更快的思考：DeepSeek-V3.1-Think 相较 DeepSeek-R1-0528，能在更短时间内得出答案
- 更强的智能体技能：后训练增强了工具使用与多步智能体任务

## API 更新

- `deepseek-chat` → non-thinking 模式
- `deepseek-reasoner` → thinking 模式
- 二者均提供 128K context
- 支持 Anthropic API 格式：见 Anthropic API 指南（API Docs）
- Beta API 支持严格函数调用（Strict Function Calling）：见 [Tool Calls 指南（API Docs）](https://api-docs.deepseek.com/guides/tool_calls.md)
- 更多 API 资源，更顺畅的 API 体验

## 工具与智能体升级

- 在 SWE / Terminal-Bench 上取得更好结果
- 面向复杂搜索任务的更强多步推理
- 思考效率大幅提升

## 模型更新

- V3.1 Base：在 V3 之上继续预训练 840B tokens，用于长上下文扩展
- Tokenizer 与 chat template 已更新——新的 tokenizer 配置见 `tokenizer_config.json`
- V3.1 Base 开源权重：DeepSeek-V3.1-Base（Hugging Face）
- V3.1 开源权重：DeepSeek-V3.1（Hugging Face）

## 定价变更

- 新定价与非高峰折扣结束于 2025 年 9 月 5 日 16:00（UTC）
- 在此之前，API 仍按当时定价计费
- 定价页：Models & Pricing（API Docs）
