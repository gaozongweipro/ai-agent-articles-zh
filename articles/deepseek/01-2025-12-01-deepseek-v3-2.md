# DeepSeek-V3.2：推动开源大语言模型的前沿

发布 DeepSeek-V3.2 与 DeepSeek-V3.2-Speciale——面向智能体打造的、以推理为先的模型。

- DeepSeek-V3.2：V3.2-Exp 的正式后继版本，现已在 App、Web 与 API 上线。
- DeepSeek-V3.2-Speciale：进一步推高推理能力边界，目前仅通过 API 提供。

技术报告：[DeepSeek-V3.2 Tech Report（Hugging Face）](https://www.deepseek.com/en/news/deepseek-v3-2/)

## 世界领先的推理

- V3.2：在推理质量与生成长度之间取得平衡，作为日常主力，性能达到 GPT-5 量级。
- V3.2-Speciale：将推理能力开到最大，可与 Gemini-3.0-Pro 相抗衡。
- 金牌表现：V3.2-Speciale 在 IMO、CMO、ICPC World Finals 与 IOI 2025 上达到金牌水平。

说明：V3.2-Speciale 在复杂任务上表现突出，但需要更高的 token 用量。目前仅提供 API（无工具调用），以便社区评测与研究。

## 工具使用中的思考（Thinking in Tool-Use）

- 引入一种大规模智能体训练数据合成方法，覆盖 1,800+ 环境与 85,000+ 条复杂指令。
- DeepSeek-V3.2 是我们首个把思考直接整合进工具使用的模型，并且在 thinking 与 non-thinking 两种模式下都支持工具调用。

## API 更新

- V3.2：用法与 V3.2-Exp 相同。
- V3.2-Speciale：通过临时端点提供：`base_url="https://api.deepseek.com/v3.2_speciale_expires_on_20251215"`。定价与 V3.2 相同，不支持 tool calls，开放至 2025 年 12 月 15 日 15:59（UTC）。
- V3.2 现已支持 Thinking in Tool-Use——细节见 [Thinking Mode 指南（API Docs）](https://api-docs.deepseek.com/guides/thinking_mode.md)。
